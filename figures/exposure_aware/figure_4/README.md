# Figure 5 source package

This legacy directory name contains the final manuscript Figure 5 source tables and plotting code: model comparison, clinical-dose fine-tuning, 18-SOC ROC curves, observed and predicted label heatmaps, and selected SOC UMAP panels.

Run `python run.py` from this directory or `python scripts/render_all_figures.py --figure "Figure 5"` from the release root.
