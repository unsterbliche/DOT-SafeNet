# Supplementary Figure 3 — off-target classification performance

Panel a uses the archived 100-epoch pretraining loss record. Panels b-d compare MTGNN, OT-ProfileNet trained from scratch and fine-tuned OT-ProfileNet using AUROC, F1 score and MCC. Each metric is stored and plotted independently.

The revised panels use four-sided frames, 9 pt axis labels, 8 pt tick labels and no panel letters. Panels b-d use a common y-axis range of 0.5-1.0. Legends are exported separately so the panel height is reserved for the data display.
