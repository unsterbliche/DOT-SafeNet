# OT-ProfileNet figure reproduction package

This directory contains the source data and Python code for Figure 2 and
Supplementary Figures 2–4. Each manuscript figure is an independent drawing
theme. Every panel has a dedicated script and output prefix; each theme also
contains a composition script for the complete figure.

## Directory structure

```text
manuscript_otprofilenet_reproducible_20260804/
├── common/                         shared typography, colors and plot primitives
├── figure_2/
│   ├── data/                       panel-specific source data
│   ├── scripts/                    plot_panel_a.py ... plot_panel_f.py
│   └── outputs/                    panels and complete figure
├── supplementary_figure_2/
├── supplementary_figure_3/
├── supplementary_figure_4/
├── qa/                             source mapping and consistency checks
├── prepare_source_data.py
├── run_all.py
├── environment.yml
└── requirements.txt
```

## Reproduction

```bash
conda env create -f environment.yml
conda activate otprofilenet-figures
python prepare_source_data.py
python run_all.py
```

Each panel can also be generated independently, for example:

```bash
python figure_2/scripts/plot_panel_c.py
python supplementary_figure_4/scripts/plot_panel_a.py
```

SVG is the editable master. PDF and PNG are generated for every panel. Complete
figures additionally receive a 600-dpi TIFF export.

## Source-data status

Figure 2, Supplementary Figure 3 and Supplementary Figure 4 can be reproduced
from the archived model outputs. Supplementary Figure 2a, 2c and 2d can also be
reproduced. Supplementary Figure 2b requires the original per-target compound
counts table. Supply a CSV containing `target_id` and `compound_count` through:

```bash
set SFIG2B_SOURCE=path/to/panel_b_compounds_per_target.csv
python prepare_source_data.py
python run_all.py
```

The complete reproduction command stops if this file is absent. For internal
checking of all available panels, use `python run_all.py --allow-missing-sfig2b`.

## Model naming

The archived weights and predictions were generated by the original PreMOTA
implementation. Figures use the manuscript display name `OT-ProfileNet`; model
outputs are unchanged.

## Data integrity

- All available observations are retained.
- No image digitization or simulated observation is used.
- The regression panels contain 45,527 archived observations before endpoint
  and target-family filtering.
- Source files and table discrepancies are documented under `qa/`.
