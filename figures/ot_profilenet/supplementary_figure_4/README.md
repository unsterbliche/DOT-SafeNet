# Supplementary Figure 4 — pK regression performance

Panels show archived observed and predicted pK values for GPCRs, ion channels,
enzymes, kinases, nuclear receptors and transporters. Each panel uses its own
source-data CSV and dedicated entry script.

The drawing code follows Figure 2c: marginal histograms touch the square main
scatter frame, family names are written inside the plot, and the composed figure
retains axis titles only along the left column and bottom row. Panel letters are
omitted. Regression metrics are recalculated from the archived observed and
predicted values without filtering or subsampling.
Data counts, metrics and rendering checks are recorded in eproduction_report.md.
