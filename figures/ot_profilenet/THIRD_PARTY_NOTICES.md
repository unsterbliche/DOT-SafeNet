# Third-party style reference

The plotting style in this package was informed by the open-source `nature-figure`
materials in [Yuan1z0825/nature-skills](https://github.com/Yuan1z0825/nature-skills),
commit `b79c022946b7bf59a30655bee726444dccf199a9`, distributed under the Apache
License 2.0.

The following elements were adapted:

- Arial/Helvetica sans-serif typography and editable SVG text;
- low-saturation method-family colors;
- removal of top and right axes;
- restrained grid lines and external shared legends;
- SVG/PDF masters with high-resolution raster previews;
- panel-level source-data and quality-assurance checks.

No third-party `figures4papers` image, manuscript-specific value, or plotting
asset is included in this package.
