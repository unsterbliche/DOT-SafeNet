# Data

- `model/`: fixed 194-target order and 18-SOC task order.
- `reference/`: target genes, target replacement background values, SOC–target evidence and SOC score backgrounds.
- `test/`: fixed DOT-SafeNet feature and label tables used for metric reproduction.
- `examples/`: four manuscript cases and a complete Citalopram 20 mg/day inference reference.

Figure-specific source tables are stored with their plotting code under `reproduce/`.
